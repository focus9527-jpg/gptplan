# Microduck 个人样机复刻方案

静态在线方案文档，预算5000元以内，借用3D打印机。

## 发布

1. 在GitHub创建仓库，例如 `microduck-plan`，默认分支为 `main`。
2. 将本文件夹内容上传到仓库根目录，包括 `.github/workflows/pages.yml`。
3. 打开 Settings → Pages → Build and deployment → Source，选择 GitHub Actions。
4. 打开 Actions，运行 Publish document to GitHub Pages，或推送一次main分支。
5. 成功后在Settings → Pages查看实际网址。常规项目网址形如 `https://用户名.github.io/仓库名/`。

也可仅上传index.html、favicon.svg和.nojekyll，通过Pages的Deploy from a branch选择main分支根目录发布。

GitHub Pages访问范围取决于账户与Pages配置；普通公开仓库部署的网站公开可见，与此前仅本人可访问的Sites页面不同。

本文为实施规划；未验证报价、硬件选型和实物参数在页面内明确标注。
